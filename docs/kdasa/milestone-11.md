# Milestone 11 — Before/After Assessment Comparison

KDASA can now compare two assessment bundles.

## Use cases

- Driver update verification
- Windows build comparisons
- Policy/blocklist changes
- Mitigation-property changes
- Research experiment baselines

The comparison reports observed changes in driver identity, signature state, PE mitigation flags, writable/executable sections, blocklist match, and review score.

It deliberately does not infer why a change occurred or whether a driver is exploitable.
